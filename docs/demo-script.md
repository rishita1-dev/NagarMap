# 3-minute SIH Demo Script

**0:00 — Problem**
Different departments maintain different representations of the same urban land parcel.

**0:20 — Ingest**
Click Start Demo. Show cadastral, revenue, municipal/building, utility and GNSS sources appearing in the dashboard.

**0:50 — Harmonize**
Open Data Integration. Show field mapping such as `khasra_no → parcel_id` and run spatial matching.

**1:20 — Detect**
Open Conflict Review. Show that geometry/attribute discrepancies become reviewable issues rather than being silently merged.

**1:45 — Visualize**
Open Map Workspace. Turn attention to the common map with multiple layers.

**2:15 — Trust**
Show confidence scores and auditability. Explain that the score is derived from actual spatial/attribute evidence.

**2:35 — Export**
Download the harmonized GeoJSON and close with the future path toward raster/imagery, DSM/DTM, GNSS/CORS and national-scale processing.
